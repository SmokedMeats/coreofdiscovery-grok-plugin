CoreOfDiscovery for Grok Bot

This package is the Grok plugin client. Decision records and scoring live on CoreOfDiscovery MCP. Agents record predictions, score them against the original request, and report calibration to the user.

This site is static documentation only. It has no database. Neon remains on CoreOfDiscovery and already scales to zero.

1. Grok Bot

  1. Create an API key in CoreOfDiscovery → Settings → API keys.
  2. Settings → Plugins → add a custom MCP server, or ask the Bot to add one.
  3. URL: {COREOFDISCOVERY_URL}/api/mcp
  4. Header x-api-key.
  5. In chat, type @ and attach the connector.

2. Grok chat connectors

grok.com/connectors → New → Custom → same MCP URL.

3. Grok Build

grok plugin install coreofdiscovery --trust

Or clone this repo and point .mcp.json at your app URL.

Tools

  • dump_claim — freeze ask + claim + P + done-when
  • list_open_claims — due / open
  • resolve_decision — grade vs frozen ask (self-grade is down-weighted)
  • calibration_report — speak D / open / overdue to the user

Env

COREOFDISCOVERY_MCP_URL=https://YOUR_APP/api/mcp
COREOFDISCOVERY_API_KEY=cod_...
