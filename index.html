Grok plugin

CoreOfDiscovery for Grok

Record a prediction, grade it later against the original request, and see how calibrated you have been. The plugin already points at production. Sign in when Grok opens Connect.

1. Sign in

  1. Install the plugin or add the MCP URL below.
  2. Call a tool. Grok should open CoreOfDiscovery (Clerk) — sign in and Allow.
  3. If Connect does not start, create a key at Settings → API keys (mcp:tools, decisions:write, calibration:read) and set x-api-key.

2. Server

Grok Build reads this from the plugin. On Bot or grok.com Custom, paste it.

https://coreofdiscovery.vercel.app/api/mcp

OAuth first. Header x-api-key only if Connect never opens.

3. Install

Grok Build

grok plugin install coreofdiscovery --trust

Grok Bot — Settings → Plugins → custom MCP → URL above. Complete Connect if prompted. In chat, type @ and attach the connector.

Grok chat — grok.com/connectors → New → Custom → same URL.

Then

Use /log-claim before a date, probability, or recommendation you cannot look up now. /grade-claim scores the frozen ask. /how-did-i-do reads calibration. If a tool returns unauthorized, use /connect.
